River Runner 德州扑克练习 · 使用说明
==================================

先看你的手机是哪种，只看对应的那一部分就行：

  安卓手机（小米、OPPO、vivo、荣耀、三星等）→ 看【一】
  华为 / 鸿蒙手机                        → 先按【一】装 APK，装不上再看【二】
  iPhone / iPad                          → 看【三】，配合网盘里的「iPhone使用教程.jpg」
  电脑                                   → 看【四】

练习软件是单机的：不用注册、没有广告、没网也能用，存档只存在你自己的手机里。
牌桌是横屏的，打开后请把手机横过来。


【一】安卓手机：安装 APK
----------------------------------
网盘里的安装包文件名类似：River-Runner-0.7.xx.apk（数字是版本号）

第 1 步：下载安装包
  在网盘 App 里点这个 .apk 文件 → 点「下载」。
  （只在网页里点开预览是装不了的，一定要下载到手机上。）

第 2 步：打开安装包
  下载完成后，在网盘 App 的「传输列表 / 下载列表」里点这个文件；
  或者打开手机自带的「文件管理」→「下载」/「最近」，找到这个 .apk 点开。

第 3 步：允许安装
  第一次装手机外的软件，系统会提示「禁止安装未知来源应用」或「出于安全考虑，已禁止安装」：
    点提示里的「设置」→ 把「允许安装应用 / 允许来自此来源的应用」打开 → 返回，再点一次安装包。
  不同手机的说法不一样，常见情况：
    小米 / 红米：可能提示「纯净模式」或要你登录小米账号，选「仍然安装」或「单次允许」即可。
    OPPO / 一加 / realme：可能要你输入锁屏密码或账号密码确认，输入后继续。
    vivo / iQOO：选「继续安装」，有安全检测就等它检测完再点安装。
    荣耀 / 华为：选「继续安装」，提示「未经检测」也选「继续安装」。
  软件没有联网功能、不读取通讯录和照片，提示风险是因为它不是从应用商店下载的。

第 4 步：打开
  安装完点「打开」，或者回桌面找「River Runner」图标（绿色底、白色扑克牌）。
  打开后把手机横过来。

以后怎么更新：
  有新版本时我会放到同一个网盘链接里，下载新的 .apk 直接安装，会覆盖旧版，存档不会丢。
  只有一种情况要先卸载：你手上是 0.2 开头的很老的版本，这种要先卸载再装（存档会清空）。


【二】华为 / 鸿蒙手机：先试 APK，装不上再用网页版
----------------------------------
先按上面【一】的步骤下载安装 APK，大部分鸿蒙手机都能直接装上，用起来也比网页版方便。

如果点开安装包出现下面这些情况，说明这台手机装不了 APK：
  · 点了没反应，或者提示「不支持此文件类型」「无法打开」「无法安装」
  · 文件管理里根本没有「安装」选项
这时候改用网页版，效果一样，只是要从浏览器打开：
  1. 用手机自带的浏览器打开网址：https://shunzhe1121.github.io/river-runner/
  2. 第一次要下载约 5MB，等加载完（1～2 分钟）。
  3. 点浏览器菜单（一般在右下角或右上角的「≡」「···」），找「添加到桌面」或「添加快捷方式」，
     以后就从桌面图标打开。找不到这个选项的话，把网址加到「收藏 / 书签」也行。
  4. 把手机横过来使用。

【三】iPhone / iPad：网页版，不用下载 App
----------------------------------
iPhone 不用装任何东西，用 Safari 打开网址，再「添加到主屏幕」，以后就跟 App 一样从桌面点开。
网盘里的「iPhone使用教程.jpg」是带图的步骤，跟着图做最简单。

网址（长按复制）：
https://shunzhe1121.github.io/river-runner/

！！重要：一定要用 Safari 打开 ！！
在微信、小红书、QQ 里直接点链接打开，是没法添加到桌面的。请复制网址，到 Safari 里打开。
Safari 就是 iPhone 桌面上那个蓝色指南针图标。

第 1 步：复制网址
  长按上面的网址 → 选中整行 → 点「拷贝」。

第 2 步：在 Safari 里打开
  打开 Safari → 点屏幕最下面（或最上面）的地址栏 → 长按 → 点「粘贴并前往」。

第 3 步：等它加载完
  第一次打开要下载约 5MB，网络慢的时候要等 1～2 分钟，期间屏幕会显示「River Runner 加载中…」和进度，别关掉。
  竖着拿手机时，加载完会显示「请把手机横过来使用」，这就说明好了。先别急着转，继续第 4 步。

第 4 步：点「分享」
  找屏幕最下面「一个方框、上面有向上箭头」的按钮，就是分享，点它。
  看不到这个按钮（新版 iOS 常见）：先点地址栏旁边的「···」或「≡」按钮，再点「分享」。

第 5 步：添加到主屏幕
  弹出的菜单里，用手指往上滑，找到「添加到主屏幕」（图标是一个带 ＋ 的方框），点它。
  第一屏没有就继续往上滑，它在比较下面的位置。

第 6 步：点「添加」
  名字不用改，直接点右上角蓝色的「添加」。
  如果有「作为网页 App 打开」的开关，保持打开。

第 7 步：从桌面打开
  回到手机桌面，会多出一个「River Runner」图标（绿色底、白色扑克牌），以后都从它打开。
  把手机横过来就可以开始练习了。添加到桌面后，没网也能用。

iPhone 常见问题：
  · 手机横过来画面不转：从屏幕右上角往下滑，打开控制中心，关掉「竖排方向锁定」（一个锁、外面一圈箭头的图标，亮着就是锁住了）。
  · 一直显示加载中 / 白屏：第一次要下载约 5MB。换个网络（Wi-Fi 和流量换一下）再试；或者关掉这个网页重新打开。
  · 存档在哪：存在这台手机的 Safari 里。删掉桌面图标、或者在「设置 → Safari」里清除网站数据，存档会一起清掉。
  · 怎么更新：不用管，会自动更新。有新版本时，联网打开一次，下次再打开就是新版。
  · iPad 也一样，按上面的步骤做。


【四】电脑
----------------------------------
用 Chrome 或 Edge 浏览器打开网址就能用：
https://shunzhe1121.github.io/river-runner/
想像软件一样打开：Chrome / Edge 地址栏右边有个「安装」小图标，点它即可。


【五】怎么玩（简单说）
----------------------------------
  · 首页点「开始练习」→ 选人数、筹码、牌桌类型 → 点「开始」。
  · 不会规则：首页「新手指南」里有规则、牌型大小、位置和术语。
  · 练习信息：牌桌右上角 ⚙ 里可以打开「练习信息」（底池赔率、所需胜率）、「每手复盘」、「数据 HUD」、「偏离提示」。
  · 想回看某一手：打牌时点右上角 ☆ 收藏，之后在「练习记录」里找；点 ⟲ 可以看上一手的复盘。
